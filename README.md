# 🌃 Night Runner

**Endless Night Runner** is a 3D endless driving game developed with Unity and C#. The player drives through a neon-lit night environment, avoids traffic obstacles, collects coins and fuel, and tries to survive as the game becomes faster and more challenging.

## 🎮 Game Features

- **Endless Driving:** A continuous road with procedurally spawned obstacles and collectibles.
- **Player Movement:** Change lanes to avoid obstacles and collect items.
- **Traffic Obstacles:** Other vehicles appear on the road and challenge the player.
- **Fuel System:** Fuel decreases over time and can be replenished by collecting fuel cans.
- **Lives & Collision:** Collisions reduce the player's remaining lives.
- **Scoring System:** Earn points by progressing and collecting coins.
- **Dynamic Difficulty:** Game speed increases as the player progresses.
- **Night Environment:** Dark blue atmosphere, neon road lines, street lights, and illuminated vehicles.
- **Visual Effects:** Neon underglow, speed effects, collision particles, collection effects, and sky fireworks.
- **Game UI:** Main menu, pause menu, restart, game-over screen, score, best score, speed, lives, and fuel indicators.
- **Settings Menu:** Music, engine, and sound effects volume controls.

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/Endless-Night-Runner.git
```

2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Choose the cloned project folder.
5. Open the project using the compatible Unity version.
6. Open the `MainScene` scene.
7. Press Play to start the game.

## 🎯 Objective

Survive as long as possible, avoid incoming vehicles, collect coins and fuel, manage your remaining lives, and achieve the highest score.
